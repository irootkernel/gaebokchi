# Architecture Decision Records

This directory owns durable records of accepted, superseded, deprecated, and
rejected architecture decisions.

No standalone ADR exists yet. The v0.1 decisions already embedded in
[the architecture](../architecture/README.md), including ARCH-01, remain
canonical current-state documentation and are not retroactively duplicated.
Create a numbered ADR here when a future decision needs alternatives, rationale,
or supersession history that should outlive an architecture rewrite.
