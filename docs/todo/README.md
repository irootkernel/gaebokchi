# TODO and Work Dossiers

This directory owns future epic-sized candidates and any explicitly established
temporary work dossier. It is not a second lifecycle or status authority.

There are currently no TODO dossier files. The vNext examples at the end of the
[roadmap](../roadmap/README.md) are preserved as the v0.1 scope boundary. Apart
from the terminal-view reset countdown adopted by EPIC-010, they are not
adopted work. A future work-definition workflow must define a candidate before
the roadmap assigns it an EPIC or TASK identifier.
