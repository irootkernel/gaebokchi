# TODO and Work Dossiers

This directory owns future epic-sized candidates and any explicitly established
temporary work dossier. It is not a second lifecycle or status authority.
Nothing here has an EPIC or TASK identifier until a work-definition workflow
adopts it into the [roadmap](../roadmap/README.md).

There are currently no TODO dossier files.

## Candidate ideas

- **Target selection for public users.** The second default Codex home,
  `~/.codex-hsy`, reflects the original owner's setup, and no option skips a
  provider. A first run therefore exits 1 for most users unless they pass
  `--codex-home` and have all three provider CLIs. A candidate epic would
  decide on configurable defaults or provider selection, which would change
  REQ-002, REQ-007, and ARCH-03.
- The roadmap's closing section lists further unadopted expansion ideas:
  persistent configuration, additional Grok accounts, full-screen interfaces,
  and watch mode.
