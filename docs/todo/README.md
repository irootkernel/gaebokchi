# TODO and Work Dossiers

This directory owns future epic-sized candidates and any explicitly established
temporary work dossier. It is not a second lifecycle or status authority.
Nothing here has an EPIC or TASK identifier until a work-definition workflow
adopts it into the [roadmap](../roadmap/README.md).

There are currently no TODO dossier files.

## Candidate ideas

Account selection now comes from `~/.config/gaebokchi/config.yaml`; users can
omit providers and configure multiple Grok homes. The earlier target-selection
candidate is implemented and is no longer future work.

Full-screen interfaces and watch mode remain unadopted ideas. There are no
open epic-sized candidate dossiers.
